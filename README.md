# 📚 演習内容

## Part A　人口・地形・公共交通をGISで診断する

### 1. 人口構造の将来推移

2025年を100として、

- 総人口
- **0～9歳人口**
- **10～19歳人口**
- 75歳以上人口

の将来変化を比較します。

年齢区分は、元データの5歳階級をそのまま合計しています。

```text
0～9歳   = 0～4歳 + 5～9歳
10～19歳 = 10～14歳 + 15～19歳
```

---

### 2. バス停までの「坂道補正距離」

同じ300mでも、平地と急坂では歩行負担が異なります。

そこで本教材では、250mメッシュの平均傾斜を使って、

```text
坂道補正距離
= 最寄りバス停までの直線距離 × 坂の補正倍率
```

を計算します。

| 250mメッシュ平均傾斜 | 補正倍率 | 直線距離300mの場合 |
|---:|---:|---:|
| 3°未満 | ×1.00 | 300m相当 |
| 3～5° | ×1.25 | 375m相当 |
| 5～8° | ×1.67 | 約500m相当 |
| 8°以上 | ×2.50 | 750m相当 |

> **注意**
>
> 「坂道補正距離」は公的な基準ではありません。  
> 250mメッシュの平均傾斜を利用して、坂を考慮するとアクセス評価がどの程度変わるかを見るための**講習用の感度分析指標**です。
>
> 実際の道路ネットワーク距離や道路勾配を表すものではありません。

最寄りバス停は、特定の事業者に限定せず、周辺のバス停全体から探索します。

---

### 3. 潜在需要メッシュの抽出

次の条件を組み合わせて、公共交通改善を検討する候補地域を抽出します。

- バス停までの坂道補正距離
- 2025年総人口
- 2025年0～9歳人口
- 2025年10～19歳人口
- 2025年75歳以上人口
- 2040年75歳以上人口
- 75歳以上人口増加（2025→2040）

例えば、

> **「2040年75歳以上人口が多く、バス停までの坂道補正距離が500m以上」**

といった条件で候補メッシュを探すことができます。

# 🚌 Part B　GTFSで「いつ・どれだけ走る？」を見る

GTFS（General Transit Feed Specification）は、公共交通の

- 路線
- 便
- 停留所
- 時刻表
- 運行日
- 路線形状

などを共通形式で表現するデータです。

本教材では、大和郡山市コミュニティバスの静的GTFSを例に分析します。

---

## 主なGTFSファイル

| ファイル | 内容 |
|---|---|
| `agency.txt` | 交通事業者 |
| `routes.txt` | 路線 |
| `trips.txt` | 各便 |
| `stop_times.txt` | 各便の停留所到着・出発時刻 |
| `stops.txt` | 停留所名・位置 |
| `shapes.txt` | 路線の経路形状 |
| `calendar.txt` | 曜日ごとの運行日 |
| `calendar_dates.txt` | 祝日・臨時運行・運休日などの例外 |
| `fare_attributes.txt` | 運賃 |
| `fare_rules.txt` | 運賃の適用条件 |
| `transfers.txt` | 乗り換え |
| `feed_info.txt` | GTFSデータ全体の情報 |

---

## GTFSで行う分析

### 路線別の平均便数

- 平日平均便数
- 土日平均便数

を比較します。

### 時間帯別便数

各便の最初の停留所の出発時刻を使って、時間帯別のサービス量を比較します。

### 停留所サービス

停留所ごとに、

- 1日停車回数
- 朝6～9時
- 昼9～16時
- 夕16～19時

の停車予定回数を集計します。

### GTFS × 250m人口

停留所周辺人口とサービス量を重ね、

```text
周辺人口 ÷ 1日停車回数
```

のような参考指標から、周辺人口に対して時刻表上のサービスが相対的に薄い場所を探します。

> これは実乗客数、混雑率、収益性を表す指標ではありません。
